# dotfiles

Personal config for my macOS and Linux (OrbStack) machines: shell, editor, terminal, VCS, and toolchain.

| Path                                    | Purpose                                                                   |
| --------------------------------------- | ------------------------------------------------------------------------- |
| `.zshrc`, `.bashrc`, `.zsh_plugins.txt` | Shell config and zsh plugins ([antidote](https://getantidote.github.io/)) |
| `.gitconfig`, `ssh.config`              | Git and SSH client config                                                 |
| `Brewfile`                              | Homebrew packages/casks (`brew bundle`)                                   |
| `.config/`                              | App config: zed, bat, eza, fzf, zsh                                       |
| `.warp/themes/`                         | Warp terminal themes (Flexoki variants)                                   |
| `init.txt`                              | macOS bootstrap: Xcode CLT, Rosetta, Homebrew                             |
| `mustafar.txt`                          | Linux VM bootstrap: packages, mise, config sync                           |
